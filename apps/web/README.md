# Portico Curb demo

Public demo: [portico-seven-rho.vercel.app](https://portico-seven-rho.vercel.app).

Browser slice of the dismissal afternoon, plus the first Campus screens. From this directory:

```bash
npm install
npm run dev
```

The server listens on port 43123. The afternoon is stored in the browser. Rules tests: `npm test`.
